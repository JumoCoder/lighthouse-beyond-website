Privacy policy

Lighthouse Beyond Idle · the game, the test advertising integration and the official website.

Draft — information and review still required
The description below reflects the current implementation, including the separate diagnostic version 0.9.27. It is not an approved public-release policy. Missing publisher details and unresolved terms are explicitly marked. No test APK is distributed here.

01. Who is responsible

Game: Lighthouse Beyond Idle. Developer contact and privacy enquiries: al.mandarinne@mail.ru.

Publisher information required: the full legal name of the person or entity responsible, country and required contact address, applicable registration details, and the effective date of the approved policy. The game title and email address do not replace this information.

This document distinguishes the regular local game from the separate advertising test build. Public production advertising has not launched. Before it does, this description must be checked against the final build and the requirements of the selected countries.

02. The game and local saves

The game code stores progress, upgrades, story entries, settings, session times and information needed to calculate offline progress on your device. The advertising test build also stores bonus timers and reward confirmations. Local backups and archives of older save formats are kept.

A separate file stores an age group, not a date of birth, the demo-ad decision and the notice version. Our game code does not currently ask for or automatically determine your region. A selection from an earlier diagnostic build may remain locally; it is not treated as verified location. Our game code does not send these fields to the advertising bridge.

The current implementation has no account registration, chat, cloud-save synchronisation or developer-operated gameplay analytics server. This does not mean that a third-party advertising SDK processes no data.

03. Yandex Mobile Ads and network data

The separate diagnostic build uses Yandex Mobile Ads SDK 8.5.0 and only the demo-rewarded-yandex test ad unit. After an adult tester explicitly allows it, the game may preload a video. An ad is shown only after a tap; an additional reward requires the SDK's reward confirmation, not simply opening or closing the ad.

Connections to Yandex services disclose an IP address and technical request information. Other data depends on the SDK version and configuration. A full examination of network recipients and payloads is not complete, so the absence of other technical identifiers or SDK telemetry is not claimed.

The inspected diagnostic APK excludes the Android Advertising ID permission and has no location permissions; SDK location tracking is disabled. The SDK receives setUserConsent(false), including after diagnostic connectivity is allowed: this choice is not represented as consent to personalisation. An IP address may still allow approximate location to be inferred.

AppMetrica components are present in transitive dependencies and must be considered when reviewing data flows. The developer has not enabled separate product analytics. Disabled automatic initialisation and our bridge logs do not establish the absence of all network activity.

Provider sources: Mobile Ads SDK data documentation and the Yandex privacy policy. Default settings in documentation are not treated as verified behaviour of this build.

VK Ads is not integrated. It is planned for a later stage and is not listed as a current advertising recipient. This document and user choices must be reviewed before integration.

04. Your choices and withdrawal

Permission is not preselected in the test build. Installing the game, choosing a language or age group, or continuing to play does not grant it. In Menu → Privacy and ads, you can leave the checkbox empty and continue, or explicitly allow demo ads and select “Continue”.

Until permission is given, our game code and Android bridge block SDK initialisation, loading and display. They also block these operations for an unknown age or an age under 18. A saved age group is not requested again. This is a conservative diagnostic rule, not the game's final content age rating.

You can use “Withdraw consent” in the same menu. It blocks new requests and displays from the game, invalidates a ready ad and does not remove rewards already earned. An in-flight network transfer may finish; withdrawal does not retroactively erase data held by the provider.

Each full restart of the diagnostic game requires fresh explicit confirmation, even if an old permission remains in a file. Returning from the background to the same process does not reset it. A write error or untrustworthy saved state must not automatically enable ads.

Gameplay and base offline progress remain available if you decline or an ad is unavailable. Legal bases and regional consent handling for public release still require verification. The present dialog is not claimed to be a certified GDPR consent solution.

05. Diagnostics and support

The test build produces local technical logs, including ad states and aggregate application network counters. Automatic uploading of these logs to the developer is not implemented. If you voluntarily send a report to support, the developer receives the information you include.

When you email al.mandarinne@mail.ru, your address, message, email metadata and chosen attachments are transmitted to handle your enquiry and investigate the issue. Gmail hosts the support mailbox; your email provider also participates. Do not send passwords, keys or unnecessary personal information.

Required before public release: approved retention periods and legal bases for correspondence and diagnostic materials, deletion procedures, provider roles and international processing terms. This draft does not invent specific retention periods.

06. This website

This is a static website hosted on GitHub Pages. Its code contains no external analytics, advertising SDKs, tracking pixels, data-submission forms, external fonts or optional cookies. RU/EN switching uses ordinary links and stores nothing in browser storage. Reading does not require JavaScript or signing in.

GitHub, as the hosting provider, receives technical connection information when a page is opened. GitHub states that visitors' IP addresses are logged for Pages security, whether or not visitors sign in. See GitHub Pages and the GitHub privacy statement. The website therefore does not claim that no data is processed.

Links to external documents and email are followed only on your action. Those services have their own rules. Reading this website does not provide consent to in-game advertising.

07. Retention, deletion and rights

Local data remains on your device until you clear application data or uninstall the app. Clearing it removes progress and local copies. We cannot recover them from a cloud server because no such server exists in the current implementation. Android backup is disabled in the inspected diagnostic APK.

You do not need to uninstall the game to decline advertising. Clearing the game does not delete information previously received by an ad provider, hosting provider or email service.

For enquiries about access, correction, deletion, withdrawal, restriction or other applicable rights, email al.mandarinne@mail.ru. Specify whether your request concerns the game, a support message or the website. Do not attach identity documents without a specific need. Available rights and procedures, including a complaint to a supervisory authority, depend on applicable law.

Still to be verified: the advertising provider's retention periods or criteria, exact legal recipients, processing countries, bases and safeguards for cross-border transfers, and applicable data-localisation requirements. We do not claim that all data remains in a single country.

08. Changes and document status

The Russian and English versions describe the same implementation. Interface language is not used as the sole basis for determining applicable rules. Material changes to providers, purposes or processing must be reflected here before new functions are enabled; where required, a new user decision will be requested.

Before a public game release, the publisher must complete their details, verify actual data flows and SDKs, retention, legal bases and international transfers, confirm age rules, and align Google Play Data Safety and RuStore disclosures. Publishing this draft on the website does not establish that these checks are complete or that the document is legally ready.
